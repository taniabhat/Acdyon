# Way.farer Landing Page

Cinematic vertical-scroll destination showcase inspired by the Adcyon reference — five full-viewport hero sections with snap scrolling.

## Destinations

1. **Iceland** — Eystrahorn mountains  
2. **Norway** — Lofoten archipelago  
3. **Patagonia** — Torres del Paine  
4. **New Zealand** — Milford Sound  
5. **Faroe Islands** — Gásadalur village  

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

Scroll vertically (or use the side thumbnails / dot indicator) to move between destinations.

## Easter egg

Konami code (↑↑↓↓←→←→BA) or hover the center logo 7 times → Adventure Mode.

## Deploy

**Vercel / Netlify:** Build `npm run build`, output `dist/`.
